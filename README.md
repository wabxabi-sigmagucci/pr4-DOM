# Практична робота №4
## Динамічна взаємодія з користувачем: маніпуляції з DOM, обробка подій та використання можливостей BOM у JavaScript

https://wabxabi-sigmagucci.github.io/pr3-DOM/

### Реалізований функціонал

- Відображення початкового списку відгуків.
- Додавання нових відгуків без перезавантаження сторінки.
- Введення імені користувача та тексту коментаря.
- Перевірка заповнення обов'язкових полів.
- Відображення повідомлень про помилки та успішне додавання відгуку.
- Автоматичне оновлення лічильника кількості відгуків.
- Очищення полів форми після успішного надсилання.
- Лічильник введених символів.
- Плавна анімація появи нових коментарів.
- Закриття повідомлення клавішею Escape.

### Використані технології

- **HTML5** — створення структури вебсторінки та форми відгуків.
- **CSS3** — оформлення інтерфейсу, темна кольорова палітра, адаптивність та анімації.
- **JavaScript (Vanilla JS)** — реалізація інтерактивності, перевірки введених даних та динамічної взаємодії з DOM і BOM.
